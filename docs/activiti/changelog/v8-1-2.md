# Version 8.1.2

**Released:** 2024-08-23

Maintenance release on the 8.1.x line with task query performance improvements and database script corrections.

## Performance Improvements

- Improved query performance for historic tasks (MNT-24335).
- Improved query performance for runtime tasks (MNT-24434).

## Bug Fixes

- Corrected the Oracle `ADD COLUMN` upgrade script.
- Added the missing `details_` column to the MariaDB schema.

## Use Cases

- **Task query performance** — if your application shows slow task list queries on the 8.1.x line, this release carries the historic and runtime task query performance improvements (MNT-24335, MNT-24434) backported from the main line.
- **Oracle / MariaDB upgrades** — corrects the Oracle `ADD COLUMN` upgrade script and adds the missing `details_` column for MariaDB, fixing broken database upgrades on those platforms.
