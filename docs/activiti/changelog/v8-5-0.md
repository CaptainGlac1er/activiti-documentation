# Version 8.5.0

**Released:** 2024-05-22

A focused maintenance release centered on a Spring Boot security patch.

## Notable Changes

- **Spring Boot upgrade to fix a vulnerability** — the platform was bumped to a patched Spring Boot release to address a known security issue (AAE-22366).

## Dependencies

- A number of dependency and build tool upgrades were applied alongside the security patch.

## Use Cases

- **Security patching** — 8.5.0 exists primarily to ship a Spring Boot security fix on the 8.x line. If you are pinned to 8.4.x for other reasons, this is the minimal upgrade to address that vulnerability.
