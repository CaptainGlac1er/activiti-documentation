# Version 8.4.0

**Released:** 2024-04-09

## New Features

- **Java 8 date support in date formatting** — `DateFormatterProvider` now supports Java 8 date/time types (AAE-21057).

## Bug Fixes

- **Variable type handling** — variable type should always resolve to `BigDecimal` where expected (AAE-27057).
- **MAP_ALL variables mapping** — fixed variable mapping for `MAP_ALL` (AAE-20402).

## Notable Changes

- Removed the disabled CSRF configuration (AAE-19764).
- Upgraded to Spring Boot 3.2.4 (AAE-21381).
- Upgraded the PostgreSQL driver (AAE-21068).
