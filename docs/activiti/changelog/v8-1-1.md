# Version 8.1.1

**Released:** 2024-07-02

Maintenance release on the 8.1.x line. Focuses on correctness fixes carried over from the 8.2.x/8.3.x work, plus schema compatibility adjustments.

## Bug Fixes

- Errors thrown in called activities are no longer swallowed by the parent process (MNT-23915).
- Boundary events handled properly in cases that previously misbehaved (MNT-22737).
- Execution listeners are no longer executed when a process instance is deleted (MNT-24081).
- Fixed subprocess with end-terminate-event combined with a user task with boundary events (MNT-24153).
- Tasks created on Activiti 5 are now visible in Activiti 7/8 applications (MNT-24405).
- The `engineVersion` field is kept in sync between memory and database (ACTIVITI-4981).
- Fixed an MSSQL query that contained a syntax error.

## Notable Changes

- Identity link table column changed from `varbinary(max)` to `LONGBLOB`.
- Apache Commons Mail upgraded on the 8.1.x line.
- `commons-email2` set to 2.0.0-M1.
- Propagation to Activiti Cloud disabled on the 8.1.x maintenance branch.

## Use Cases

- **Staying on the 8.1.x baseline** — this release backports the engine correctness fixes (boundary events, called-activity error propagation, execution listeners on deletion) to teams that cannot move to 8.2.0+ yet.
- **Database compatibility** — the `LONGBLOB` change and MSSQL query fix make 8.1.x viable on MySQL/MariaDB and SQL Server where the previous schema or queries failed.
