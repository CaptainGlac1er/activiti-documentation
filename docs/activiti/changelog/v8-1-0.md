# Version 8.1.0

**Released:** 2023-11-21

## New Features

- **Identity link details** — the identity link API is extended with a user identity details attribute (AAE-16959), including MySQL upgrade scripts for the new column.
- **`involvedGroupsIn()` query** — new query capability on `ProcessQuery` for both `HistoricProcessInstanceQuery` and `ProcessInstanceQuery` (ACTIVITI-1291 backport).

## Notable Changes

- `getEngineServices()` added to execution, allowing access to engine services from delegate code (MNT-23965).
- H2 definitions fix (AAE-16885).
- General build improvements (AAE-16883).

## Use Cases

### Querying process instances by candidate groups

`involvedGroupsIn()` narrows active and historic process instance queries to instances where any of the given groups participates (as candidate users, candidate groups, or owners) — useful for group-level dashboards and audits:

```java
import java.util.List;
import org.activiti.engine.RuntimeService;
import org.activiti.engine.runtime.ProcessInstance;

List<ProcessInstance> instances = runtimeService.createProcessInstanceQuery()
    .involvedGroupsIn(List.of("accounting", "management"))
    .list();
```
