# Version 8.1.0

**Released:** 2023-11-21

## New Features

- **Identity link details** — the identity link API is extended with a user identity details attribute (AAE-16959), including MySQL upgrade scripts for the new column.
- **`involvedGroupsIn()` query** — new query capability on `ProcessQuery` for both `HistoricProcessInstanceQuery` and `ProcessInstanceQuery` (ACTIVITI-1291 backport).

## Notable Changes

- `getEngineServices()` added to execution, allowing access to engine services from delegate code (MNT-23965).
- H2 definitions fix (AAE-16885).
- General build improvements (AAE-16883).
