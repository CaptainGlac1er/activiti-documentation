# Version 8.6.0

**Released:** 2024-07-05

## New Features

- **Activiti 5 task visibility** — tasks created in Activiti 5 are now visible in Activiti 7/8 applications (MNT-24405).

## Notable Changes

- Upgraded XmlUnit to mitigate a security issue (AAE-22375).
- Numerous dependency and build tool upgrades (Maven plugins, CodeQL, alfresco-build-tools).

## Use Cases

- **Activiti 5 to 8 migration** — if you are cutting over from an Activiti 5 deployment and expect users to pick up tasks created under the old system, this is the release where those tasks become visible in the new application.
- **Security patching** — the XmlUnit upgrade addresses a known vulnerability, so this is the minimum version to run if you are still on 8.5.x or earlier.
