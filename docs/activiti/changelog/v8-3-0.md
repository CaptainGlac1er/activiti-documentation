# Version 8.3.0

**Released:** 2024-03-05

## New Features

- **Nashorn script engine integrated** — JavaScript (Nashorn) scripting support is now part of the core, so script tasks and script-based constructs can run without extra configuration (AAE-14392).
- **Decimal primitive type** — a new primitive type registered for decimal process variables (AAE-19479).

## Bug Fixes

- Fixed an issue where execution listeners were executed when a process instance is deleted (MNT-24081).
- Fixed subprocess with end-terminate-event and user task with boundary events (MNT-24153).
- Fixed MSSQL create and upgrade schema scripts.
- Identity link table column changed from `varbinary(max)` to `LONGBLOB`.

## Notable Changes

- Upgraded to Spring Boot 3.2.x (3.2.1, then 3.2.2).

## Use Cases

### JavaScript script tasks without extra dependencies

With the Nashorn engine bundled in the core, script tasks can use JavaScript out of the box — no additional script engine dependency in your application:

```xml
<scriptTask id="greet" name="Greet" scriptFormat="javascript">
  <script><![CDATA[
    var name = execution.getVariable("customerName");
    execution.setVariable("greeting", "Hello " + name);
  ]]></script>
</scriptTask>
```

### Precise numeric variables

Process variables can now be declared with the `bigdecimal` type in the process extension JSON. Values are parsed to `BigDecimal` (from numbers or numeric strings) and validated as numeric, avoiding floating-point rounding issues for monetary or measurement data:

```json
{
  "properties": {
    "amount": {
      "name": "amount",
      "type": "bigdecimal",
      "required": true
    }
  }
}
```
