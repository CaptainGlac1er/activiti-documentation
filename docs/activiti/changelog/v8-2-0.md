# Version 8.2.0

**Released:** 2024-01-22

## Notable Changes

- **Upgraded to Java 21** (AAE-17001).
- **Upgraded to Spring Boot 3.2** (AAE-17000).

## Bug Fixes

- Errors thrown in called activities are no longer swallowed by the parent process (MNT-23915).
- Boundary events handled properly in cases that previously misbehaved (MNT-22737).
- The `engineVersion` field is now kept in sync between memory and database (ACTIVITI-4981).
- Fixed SQL syntax errors in `Deployment.xml`.

## Other Changes

- New CI workflows allowing external contributions.

## Use Cases

- **Modern JVMs** — 8.2.0 is the release line to adopt if you want to run the engine on Java 21 with Spring Boot 3.2; the 8.1.x line stays on the older baseline.
- **Boundary event and called-activity correctness** — if you hit misfiring boundary events or errors swallowed by parent processes, the fixes for both (MNT-22737, MNT-23915) are included here (and backported to 8.1.1).
