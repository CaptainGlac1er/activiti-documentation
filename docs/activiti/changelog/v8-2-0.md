# Version 8.2.0

**Released:** 2024-01-22

## Notable Changes

- **Upgraded to Java 21** (AAE-17001).
- **Upgraded to Spring Boot 3.2** (AAE-17000).

## Bug Fixes

- Errors thrown in called activities are no longer swallowed by the parent process (MNT-23915).
- Boundary events handled properly in cases that previously misbehaved (MNT-22737).
- The `engineVersion` field is now kept in sync between memory and database (ACTIVITI-4981).
- Fixed SQL syntax errors in `Deployment.xml`.

## Other Changes

- New CI workflows allowing external contributions.

## Breaking Changes & Mitigations

- **Requires Java 21** — this is the first release built on Java 21 (8.1.x targets Java 17). **Mitigation:** upgrade the JDK of your build and runtime; stay on the 8.1.x line if you must remain on Java 17.
- **Spring Boot 3.2 baseline** — the platform moved from Spring Boot 3.1 to 3.2. **Mitigation:** review the [Spring Boot 3.2 release notes](https://github.com/spring-projects/spring-boot/wiki) for framework-level changes if you pin Spring dependencies yourself.
- **Error propagation in called activities (behavior change)** — same fix as in 8.1.1: errors handled inside a called process no longer bubble up to the parent's call activity boundary (MNT-23915). **Mitigation:** re-test call-activity error flows and place boundaries where handling is intended.
- **Boundary event handling (behavior change)** — boundary event triggering edge cases corrected (MNT-22737). **Mitigation:** review processes with multiple competing boundary events.

## Use Cases

- **Modern JVMs** — 8.2.0 is the release line to adopt if you want to run the engine on Java 21 with Spring Boot 3.2; the 8.1.x line stays on the older baseline.
- **Boundary event and called-activity correctness** — if you hit misfiring boundary events or errors swallowed by parent processes, the fixes for both (MNT-22737, MNT-23915) are included here (and backported to 8.1.1).
