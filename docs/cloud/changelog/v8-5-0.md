# Version 8.5.0

**Released:** 2024-05-22

## New Features

- **Permission-based authorization** — identity permissions are now enforced on cloud endpoints (AAE-21097), including fixes for NPEs when reading permissions (AAE-22123) and previously omitted permission methods (AAE-22123).

## Bug Fixes

- Fixed "detaching an uninitialized collection" log noise and improved task search query performance (AAE-22075).

## Notable Changes

- **Security patch** — Spring Boot upgraded on the 8.4.x/8.5.x line to address a vulnerability (AAE-22648).
- **Schema** — new index on the audit-event table (AAE-22469).
- `graphql-jpa-query` upgraded to 1.2.5 (AAE-22485).
- Swagger API docs now recommend the HAL-JSON format (AAE-18428).
