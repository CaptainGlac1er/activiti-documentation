# Version 8.1.0

**Released:** 2023-11-21

## New Features

- **Actor tracking in events** — the actor is extracted from the execution context and attached to `PROCESS_STARTED` events (AAE-17650) and to events sent to the centralized Audit service (AAE-14357), so audit trails can attribute actions to the acting user.

## Bug Fixes

- Fixed duplicate key violations on `process_instance_pkey` and `bpmn_activity_pkey` (AAE-18015/AAE-18003).
- Fixed importing a single model from a process definition archive (AAE-17863).

## Notable Changes

- Stopped using a global variable to track ids to update (AAE-16625).
- Added a file upload size/type check to the deployment endpoint (AAE-17239).
- Reduced GraphQL broker logging noise (AAE-17856).
- `graphql-jpa-query` upgraded to 1.1.2.
