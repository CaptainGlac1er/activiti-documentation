# Version 8.2.0

**Released:** 2024-01-22

## New Features

- **Lazy loading of variable values** — the Query service loads variable values lazily, reducing memory and query cost (AAE-18268).
- **Configurable Keycloak token lifespan** — `access.token.lifespan` is now configurable (AAE-18070).
- **Java date/time support** — variable values of Java date/time types are supported (AAE-19196).

## Bug Fixes

- Fixed a Query service memory leak caused by an unbounded JPA criteria query over process tasks (AAE-18520).
- Reduced the Audit service memory footprint from dynamic insert overhead in audit entities (AAE-18550).
- Fixed the Hibernate `HHH000104 firstResult/maxResults` warning regression in Query (AAE-18268).
- Process definition zip uploads are validated by content only, ignoring zip headers (AAE-18620).

## Notable Changes

- **Security** — CSRF protection enabled, with public URLs excluded (AAE-16343, AAE-19071).
- The JUEL module was removed (AAE-19031).
- `org.json` and everit JSON schema versions upgraded (AAE-17719/AAE-17736).

## Breaking Changes & Mitigations

- **Java 21 required** — the build and runtime move to the Java 21 SDK (AAE-17001). **Mitigation:** upgrade your JDK and container base images to 21.
- **Spring Boot 3.2 / Spring Cloud 2023.0.0 baseline** — the platform is upgraded to Spring Boot 3.2 and Spring Cloud 2023.0.0 (AAE-17000). **Mitigation:** review the Spring Boot 3.2 release notes if you pin Spring dependencies yourself.
- **JUEL removed** — the JUEL expression module is no longer shipped (AAE-19031). **Mitigation:** ensure your runtime bundle uses a supported EL implementation.
