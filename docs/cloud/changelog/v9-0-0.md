# Version 9.0.0

**Released:** 2026-03-05

Major release. The cloud platform moves to the Java 25 baseline and expression evaluation is moved behind the `jakarta.el.ExpressionFactory` SPI — mirroring the [engine 9.0.0 release](/changelog/9.0.0).

## Breaking Changes & Mitigations

- **Java 25 required** — the platform is built and runs on Java 25 (AAE-38730). **Mitigation:** upgrade your JDK and container base images to 25 before deploying.
- **Expression evaluation behind an SPI** — the runtime expression manager is configured to use the `jakarta.el.ExpressionFactory` SPI (Apache implementation, AAE-42981). **Mitigation:** if you provide or depend on a specific EL implementation, ensure it is available as a `jakarta.el.ExpressionFactory` implementation on the classpath.

## Notable Changes

- **Linked/orphan process filtering rework** — process filtering logic was refactored to combine linked-process and orphan-process criteria in a single pass (AAE-42835), building on the linked/orphan filtering introduced in 8.8.0.
- Obsolete testcontainers workarounds removed.
- Inherited the engine 9.0.0 changes (see the [engine changelog](/changelog/9.0.0) for the full list).

## Bug Fixes

- Fixed a flaky test in `FunctionRouterBindingConfigurationIT` (test infrastructure only).
