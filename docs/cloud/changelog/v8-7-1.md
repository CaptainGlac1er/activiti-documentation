# Version 8.7.1

**Released:** 2025-08-22

Maintenance release on the 8.7.x line.

## New Features

- **Count APIs** — new endpoints to count tasks and process instances without fetching the full result sets (AAE-37326). Useful for rendering badge counts and total labels in UIs without the cost of a paged query.
