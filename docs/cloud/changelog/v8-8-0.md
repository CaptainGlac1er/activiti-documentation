# Version 8.8.0

**Released:** 2026-02-25

The largest release in this range. The headline features are **linked process instance support** (filtering and linking orphans in the Query service), **subprocess visibility** in the process instance API, and a rework of connector message routing with **multiplexed bindings**.

## New Features

- **Linked process instances** — process instances now carry a linked process instance id and a root process instance id (AAE-38369, AAE-33087, AAE-37399). New APIs: list linked processes of a main process (AAE-39666), retrieve linked processes by instance id (AAE-39671), and link an orphan process instance to a main process (AAE-38371).
- **Linked/orphan filtering in search** — the process instance search endpoint can filter out linked processes (AAE-39686) and unlinked/orphan processes (AAE-39689), and `/processInstance` accepts filters by linked process instance id and root process instance id (AAE-41244).
- **Subprocess visibility** — new `includeSubprocesses` parameter on process instance search (AAE-39667), a subprocess list on the process instance controller (AAE-39665), and an admin endpoint to list subprocesses (AAE-39861). Admin users can see the subprocess list of processes started by other users (AAE-40576).
- **Count APIs** — count endpoints for tasks and process instances (AAE-37326).
- **Connector message multiplexing** — multiplex message bindings configuration for connector types and for runtime applications (AAE-35743), anonymous-consumer function router message multiplexing (AAE-35743), and demultiplexing connector messages using a single queue (AAE-35579).
- **RabbitMQ message prefixes** — optional RabbitMQ prefix in Activiti Cloud messaging configuration (AAE-38295), including Rabbit compression/decompression payload configuration (AAE-39352).
- **Incident events** — new `CreateIncidentEventCmd` to handle incident event sending (AAE-40706).
- **Message router error handlers** — error handler definition support for message routers (AAE-39919).
- **Process definition endpoint options** — `include` parameter on get-all process definitions (AAE-38145), `excludeCategory` parameter on process definitions endpoints (AAE-37007), and an `actor` filter in GraphQL subscriptions (AAE-36828).
- **Integration context enrichers** — the possibility to inject integration context enrichers (AAE-33132).
- **Constant values decorator** — constant values decorator on the admin process definitions endpoint (AAE-33028).
- **Ephemeral variables in query results** — `ephemeral` field on variables returned by the Query service API (AAE-31941), with the ephemeral column set on existing variables (AAE-33867) and ephemeral handling for connector events (AAE-38556).
- **Process instance variables feign client** — feign client and configuration for process instance variables (AAE-34291).
- **Unbounded max AppVersion** — removed the cap on application version (AAE-39563).
- **Delayed publishing** — ability to republish discarded events so another node consumes them instead of retrying on the same node, plus configurable delay and default values (AAE-34337).

## Bug Fixes

- Fixed a duplicate key violation on `bpmn_activity_pkey` (AAE-42642).
- Fixed linked processes mapping (AAE-42027).
- Fixed the process definition list returning all process versions (AAE-36801).
- Fixed the Query service "Failed to send Message" problem (AAE-39373).
- Fixed a race condition for service tasks using connectors (AAE-23532 — carried into this line).
- Fixed an NPE in the `ProcessVariableEntity` ephemeral attribute when accessed through the entity manager with nullable values.
- Fixed function router exchange header fallback when the RabbitMQ prefix is enabled (AAE-41073).
- Fixed multiplex message bindings configuration with an empty connector type (AAE-35743).
- Fixed Spring Cloud Stream case-sensitive binding property matching after the Spring Boot 3.5 upgrade (AAE-39994).
- Fixed a GraphQL `NullPointer` in request processing (AAE-30789).
- Constant and static values are now fetched properly (AAE-32880).
- Errors in the integration result handler are now caught and the task is marked as failed (AAE-35904).
- `CloudBpmnError` propagation is no longer logged as an error (AAE-36864).
- Event handlers no longer log message payloads (AAE-37863).
- Return 400 (instead of 500) for bad request searches (AAE-35733).
- Improved error handling for `ConversionFailedException` (AAE-30844).

## Notable Changes

- **Audit chunking** — audit events are split into chunks to avoid sending large messages (AAE-38416).
- **Schema indexes** — composite and ascending-timestamp indexes on `audit_event` (AAE-42615, AAE-42642), `entity_id` index on audit tables (AAE-37542), and audit table performance indexes (AAE-35605).
- **Sorting behavior** — sorting now places nulls at the end (AAE-35609).
- **Removed** — the unused Eureka module (AAE-41210), the process instance/definition category filter (AAE-40256), the old WebSocket feature flag and endpoint (AAE-26893), and the `userInfo` endpoint call when the openid scope is missing (AAE-39538).
- **Integration context** — the relationship between `IntegrationContextEntity` and `ServiceTaskEntity` changed (AAE-39413).
- **`sub` claim** — added to the user security context (AAE-33179).
- **Health checks** — trigger health check failure for missing durable queues (AAE-33554).
- Upgraded to Spring Boot 3.5.x and aligned Keycloak to 26.5.0.

## Breaking Changes & Mitigations

- **Spring Boot 3.5 baseline** — the platform moves from Spring Boot 3.3 to 3.5 (3.5.6). **Mitigation:** review the Spring Boot 3.4/3.5 release notes if you pin Spring dependencies yourself; note the case-sensitive binding property matching fix (AAE-39994) if you use custom Spring Cloud Stream binding names.
- **Connector message routing rework** — connector messages are now demultiplexed using a single queue, with multiplexed bindings per connector type (AAE-35579, AAE-35743). **Mitigation:** review your connector binding configuration if you rely on per-connector queues or the previous routing behavior.
- **Task name and description truncated** — values are truncated to a maximum of 255 characters (AAE-37567), mirroring the engine behavior. **Mitigation:** if you relied on the previous failure, add your own validation.
- **Integration context entity relationship** — the relationship between `IntegrationContextEntity` and `ServiceTaskEntity` changed (AAE-39413). **Mitigation:** if you access these entities directly, re-validate your code against the new relationship.
- **Removed endpoints** — the old WebSocket endpoint and category filters were removed (AAE-26893, AAE-40256). **Mitigation:** migrate to the replacement APIs before upgrading.

## Use Cases

### Finding orphan process instances

Processes started without a parent (or whose parent link was lost) can now be found and linked:

```
GET /v1/process-instances?includeOrphans=true
POST /v1/process-instances/{id}/link   { "mainProcessInstanceId": "..." }
```

The search endpoint's linked/orphan filters let dashboards show only top-level processes, only orphans, or the full hierarchy — see the [Query service](../services/query.md) documentation.

### Showing subprocesses of a process instance

```
GET /v1/process-instances/{id}?includeSubprocesses=true
```

Subprocesses are returned as part of the process instance payload, so UIs can render a process with its children in a single call.
