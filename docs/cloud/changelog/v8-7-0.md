# Version 8.7.0

**Released:** 2025-02-03

Feature-heavy release centered on the Query service: **process variable filters**, **sorting by process variables**, and a security-critical **querydsl replacement**, plus a rework of GraphQL transport.

## New Features

- **Process variable filters** — filter tasks and process instances by process variable key/value (AAE-22454), including "not equals" filters (AAE-28598), range filters (AAE-23154), and task-variable and process-variable filters working simultaneously (AAE-25704).
- **Sorting by process variables** — sort tasks (AAE-25188) and process instances (AAE-25189) by process variable values; the sorting API accepts `processDefinitionKey` as a list (AAE-25189).
- **Process instance entity filters** — new filters for process instance search, including status (AAE-28069), process definition name (AAE-23194, AAE-29004), and new task/process-instance filter fields (AAE-28084).
- **Date range filters** — audit events search (AAE-29493) and the admin service task endpoint (AAE-29345).
- **Process definition synchronization** — process definitions are synchronized between Runtime Bundle and Query services (AAE-26100).
- **Start event constants endpoint** — retrieve start event constants (AAE-25430); start form constants fixed for processes with no form (AAE-25834).
- **Activiti Spring Cache Manager provider** — new cache manager provider for cloud applications (AAE-29208).
- **Security context scopes** — OAuth2 scopes are read from the token and placed in the Spring security context (AAE-24051).
- **Audited export scoping** — the scope of audit event export data is now limitable (AAE-24320).

## Bug Fixes

- **HQL injection** — the `querydsl` dependency was replaced with a patched version of an OpenFeign fork to fix an HQL injection vulnerability (AAE-29930), with the conflicting `querydsl` version property renamed (AAE-29930).
- Fixed bigdecimal filtering precision issues (AAE-29955).
- Fixed datetimes being displayed as dates (AAE-29974).
- Fixed the consumer throwing a "missing anonymous queue" exception (AAE-29225).
- Fixed process variable sorting (AAE-28952).
- Fixed a missing task in the task search response (AAE-28837).
- Fixed Query application GraphQL not paging results properly (AAE-28895).
- Fixed pagination issues in the new search endpoint (AAE-27933).
- Fixed an NPE regression when deleting a cancelled process instance (AAE-22831) and status wrongly changing to 'Cancelled' on deletion (AAE-22831).
- Fixed Query service OOM caused by infinite/unbounded service task instances (AAE-25958).
- Fixed slow GraphQL queries caused by a redundant JPA fetch with empty keys (AAE-26198).
- Fixed deserialization issues (AAE-22454).
- Fixed the task list not showing tasks when process variables were added to "Column process variables" (AAE-22454).
- Fixed the GraphQl `LOCATE` search exception for string parameters (AAE-35609 range).
- Fixed a race condition for service tasks using connectors (AAE-23532).

## Notable Changes

- **GraphQL over WebSocket** — switched to the Spring implementation of GraphQL over WebSocket (AAE-20807), with the GraphQL library upgraded.
- **Module split** — Query Consumer and Audit Consumer were refactored into separate starter modules (AAE-23121).
- **Schema indexes** — indexes for task id/name/status (AAE-25756), task and task_process_variable (AAE-25874), and task owner/assignee/initiator (AAE-25756); the process variable index is dropped when the field type changes from text to jsonb (AAE-25756).
- **Response codes** — search endpoint restrictions applied (AAE-25937) and internal server errors changed to 4xx where appropriate (AAE-24227).
- **Process definition description** — allowed size increased (AAE-25947).
- Removed the Alfresco process SDK propagation (AAE-26120).
- Swagger refresh-token handling moved to a custom `custom-swagger.js` (AAE-23742).
- Upgraded to Spring Boot 3.3.x (final 3.3.5) and testcontainers-keycloak 3.3.1.

## Breaking Changes & Mitigations

- **Spring Boot 3.3 baseline** — the platform moves from Spring Boot 3.2 to 3.3. **Mitigation:** review the Spring Boot 3.3 release notes if you pin Spring dependencies yourself.
- **querydsl replacement (security)** — the `querydsl` package was replaced with a patched fork (AAE-29930). **Mitigation:** if your custom code depends on querydsl classes directly, align with the patched fork's package.
- **Consumer starter split** — Query and Audit consumers are now separate starter modules (AAE-23121). **Mitigation:** update your application's dependency coordinates if you consume these starters directly.
- **GraphQL WebSocket transport** — the WebSocket implementation changed to Spring's (AAE-20807). **Mitigation:** re-test GraphQL subscriptions against the new transport.
