# Version 8.4.0

**Released:** 2024-04-09

## New Features

- **`hideDisabledUser` user search parameter** — user search in the identity adapter supports hiding disabled users, with corresponding Keycloak logic (AAE-21177).

## Bug Fixes

- Fixed a variable type mapping regression (AAE-21097).
- Variable values are consistently treated as `bigdecimal` where expected (AAE-20757).
- Fixed "dispatcher has no subscribers for channel 'rb.discardChannel'" (AAE-21015).
- Avoided an error when deleting a token used for Docker Hub deletion (AAE-21078).

## Notable Changes

- **Modeling code removed** — remaining modeling-related code and acceptance tests were removed from the cloud platform (AAE-20804, AAE-20785).
- Spring Boot upgraded to 3.2.4 (AAE-21381).
- `hibernate-enhance-maven-plugin` version configuration fixed (AAE-21801).
