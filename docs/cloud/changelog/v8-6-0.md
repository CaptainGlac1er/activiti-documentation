# Version 8.6.0

**Released:** 2024-07-05

## New Features

- **Aggregated data in GraphQL** — the Query service GraphQL schema now supports querying aggregated data (AAE-22508), with inline documentation added to the schema.
- **Application versions endpoint** — new endpoint to get application versions for process instances (AAE-23393).

## Bug Fixes

- Fixed a task search performance regression when searching by task variable name and value (AAE-23492).

## Notable Changes

- **Schema indexes** — new index on task name (AAE-22650) and an index to improve bulk delete performance (AAE-22912).
- **Pagination limit** — requesting a page size beyond the limit now returns an exception instead of failing unpredictably (AAE-22377).
- Swagger UI switched to codeflow for the API docs (AAE-23482).
- Reduced logging noise (`log.warn` replaced with `debug` in hot paths, AAE-22627).
