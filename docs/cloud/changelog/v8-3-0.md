# Version 8.3.0

**Released:** 2024-03-05

## New Features

- **Service account client support** — new logic to handle service account clients in the identity adapter (AAE-19408).
- **Parameterized user type** in user search queries (AAE-19797).
- API docs: descriptions and tags added to the Runtime Bundle REST API (AAE-19477).

## Bug Fixes

- `GET /process-instances/{id}/tasks` no longer ignores paging and sort parameters (AAE-20169).
- `GET /tasks` honors `maxItems` when a variable filter is used (AAE-19748).
- Fixed the error message shown when launching `/graphiql` from the Query service (AAE-20229).
- Fixed notification content to emit correct JSON, and downgraded GitHub notification noise to a warning (AAE-19607).

## Notable Changes

- **Idempotent BPMN message receiver** — the idempotent BPMN receiver interceptor now discards duplicate messages into the error channel instead of failing (AAE-20974); the legacy cloud-stream error handler for functional connector bindings was refactored to be compliant (AAE-20915).
- Reduced logging on WebSocket connection errors (AAE-20417).
- Upgraded to Spring Boot 3.2.x (3.2.2).
